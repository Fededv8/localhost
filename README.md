Talabartería El Moro

Sitio web para Talabartería El Moro, comercio de artículos de talabartería y campo (botas, mantas, monturas, recados, cojinillos y accesorios de cuero) ubicado en Ciudad Autónoma de Buenos Aires, Argentina.

Incluye catálogo interactivo por categorías, carrito de compras con persistencia local y pedido de compra vía WhatsApp.

Sitio 100% estático — no requiere backend, base de datos ni proceso de build. Se puede abrir directamente en el navegador o subir tal cual a cualquier hosting.

🛠️ Tecnologías
Área	Tecnología
Estructura	HTML5
Estilos	CSS3 vanilla (variables CSS, sin frameworks)
Interactividad	JavaScript vanilla (ES6+), sin librerías
Tipografía	Google Fonts (Rye, Fraunces, Karla)
Mapa	Google Maps Embed (sin API key)
Persistencia	localStorage del navegador
Contacto	Enlaces a WhatsApp (wa.me), Instagram, Facebook y TikTok
Íconos	SVG inline dibujados a mano (sin librerías de íconos)

No usa frameworks (React, Vue, Bootstrap, Tailwind, etc.) ni herramientas de build (Webpack, Vite, npm). Es un único archivo index.html autocontenido.
